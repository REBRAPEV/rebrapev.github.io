# Design and template notice

This website was developed using Henrik Bradtmüller's Academic Pages-based personal website as a structural reference and after reviewing the current Academic Pages project (https://github.com/academicpages/academicpages.github.io).

Academic Pages is derived from the Minimal Mistakes Jekyll theme. The original theme is Copyright (c) 2016 Michael Rose and distributed under the MIT License. A copy of that license is included in this repository.

The REBRAPEV-specific layouts, copy, and CSS in this repository were written as a reduced, network-oriented implementation rather than as a wholesale copy of the Academic Pages theme.
